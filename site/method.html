Method

From graded answers to skill estimates

Subsigmoid uses two established models from psychometrics. A language model is used only to label the questions.

1Inputs

A graded test in one of three forms: a Gradescope export, multiple-choice answers, or responses collected by our web quiz. In a Gradescope export, each rubric item is a separate observation, so a five-point question gives up to five pieces of evidence instead of one.

Grades are already structured data. They are reshaped into one row per student per item and joined to the question tags by item ID.

2Tagging

First, a short list of skills is fixed, either from the syllabus or proposed by the language model and approved by the teacher. The model then marks which skills each question and rubric item requires. For multiple choice, it also labels each wrong option with the mistake it reflects.

The result is a table of ones and zeros called the Q-matrix. The language model receives question text only. It never sees student names or answers.

3Question model

Item response theory describes each question with a curve: the probability that a student of ability θ answers correctly.

P(correct) = c + (1 − c) · σ(a(θ − b))

b is difficulty, a is discrimination (how sharply the question separates stronger from weaker students), and c is the guessing floor, set to one over the number of options. With a class of about 40 students we fix a or give it a prior; with larger classes it is estimated. Questions with low discrimination are listed in the test report.

The same curve gives the chance that a correct answer was a guess. Under the curve, a correct answer comes either from knowing the material or from a lucky guess; the second share is c(1 − σ) / P.

4Skill model

We use DINA, a cognitive diagnosis model. Each student either has or lacks each skill. A student with every skill a question requires answers correctly unless they slip. A student missing any required skill answers correctly only by guessing. Slip and guess rates are estimated per question with expectation-maximization, over all combinations of skills.

The method depends on questions that share skills. In the example below, Ana and Ben both scored 10 of 18. Ana missed every question involving negatives. Ben answered the two questions that combine skills correctly, which is hard to do without those skills, so his four misses are explained better as slips.

Skill estimates are only identifiable when each skill appears in at least a few questions, including some that test it alone. The test report says when this is not the case.

5Answer labels

Combining both models, each answer gets one of four labels, with a probability.

When the probability is close to even, the answer is reported as undetermined. If a question’s answers fit its tags poorly, for example when students who lack a required skill still answer it correctly at a high rate, the question is sent back for re-tagging.

6Evaluation

For each student we hide one answer and predict it from their other answers. We compare four methods. If Subsigmoid does no better than item response theory alone, the skill model is not adding information.

7Limits

  • Small classes give wide uncertainty. Results are shown with their ranges.
  • Tags can be wrong. The tag check catches some errors, not all.
  • A “guess” label is a statement about evidence, not about honesty.
  • The output describes a score. It is not meant to replace one, and student views do not compare students.
