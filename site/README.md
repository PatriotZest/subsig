# Subsigmoid web front end

Static HTML/JS, no build step.

- `index.html`: front page
- `app.html`: teacher dashboard (course, exam, student, live session, import)
- `quiz.html`: the quiz people take on their phones
- `method.html`: how the statistics work

Run it locally:

```bash
cd site && python3 -m http.server 8771
```

Then open http://localhost:8771.

Until the backend is connected, every page reads sample data from `data/` through `js/api.js`.
To point the site at the backend, set `<meta name="subsigmoid-api" content="https://...">` in each page's head
(or add `?api=https://...` to the URL). The endpoints and data shapes are in `API.md`.

Sample data is generated by `../tools/make_sample_data.py`. Brand assets (logo, icon) are in `../brand/`.
